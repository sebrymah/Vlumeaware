Security & compliance

Isolation and consent are structural, not promises.

Vlumeaware is the kind of tool that phishes people and holds sensitive rosters — so it’s built defensively from the data layer up.

  • Query-layer tenant isolation. Every read and write is scoped to one client; there is no shared view by accident.
  • Consent gate. No simulation runs without signed authorization on file.
  • Domain-ownership gate. Recipients are confined to DNS-verified domains — enforced when adding people and again at send.
  • Metadata-only capture. A simulated login records that a submission happened, never the password typed.
